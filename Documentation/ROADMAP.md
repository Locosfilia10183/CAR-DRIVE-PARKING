# Development Roadmap

The project is developed in small, testable milestones. Each phase should be playable or verifiable before the next major phase begins.

## Phase 0 — Foundation
- [x] Create GitHub repository
- [x] Add initial game concept and documentation
- [x] Define first prototype scope
- [ ] Set up Unity project on a development computer
- [ ] Configure Unity version control workflow

## Prototype 0.1 — Driving Core
- [ ] Create a simple test scene
- [ ] Add the first placeholder vehicle
- [ ] Implement steering and vehicle movement
- [ ] Implement throttle, braking and reverse
- [ ] Tune suspension and wheel contact
- [ ] Add exterior camera
- [ ] Add interior camera
- [ ] Add keyboard controls
- [ ] Add a marked parking area
- [ ] Test a basic mobile touch-control layout
- [ ] Test performance and stability

**Exit criteria:** A player can drive, stop, reverse, change camera and park the vehicle in the test area.

## Prototype 0.2 — Garage and Vehicles
- [ ] Basic garage scene
- [ ] Vehicle selection
- [ ] Vehicle data configuration
- [ ] First three fictional vehicles
- [ ] Basic paint and wheel customization
- [ ] Save local player progress

## Prototype 0.3 — Neustadt Vertical Slice
- [ ] Build a small, optimized city area
- [ ] Add roads, signs and road markings
- [ ] Add basic traffic prototype
- [ ] Add one or two mission prototypes
- [ ] Add navigation and minimap prototype
- [ ] Test mobile and PC performance

## Alpha 0.4 — Online Foundation
- [ ] Choose and validate backend hosting
- [ ] Account and authentication design
- [ ] Dedicated authoritative session server
- [ ] Basic player synchronization
- [ ] Initial 16-player load and stability tests
- [ ] Cross-platform input and UI testing

## Alpha 0.5 — Economy and Activities
- [ ] Server-validated currency
- [ ] Dealership and vehicle ownership
- [ ] Parking and driving school activities
- [ ] Delivery and taxi missions
- [ ] Vehicle upgrades
- [ ] Secure trading design

## Beta 1.0 — Expansion and Release Preparation
- [ ] Expand the city and road network
- [ ] Improve traffic and world simulation
- [ ] Add social and multiplayer activities
- [ ] Accessibility and localization pass
- [ ] Performance and device compatibility pass
- [ ] Privacy, security and moderation review
- [ ] Store and release preparation

## Development rule
Do not build the full online world before the driving core is fun and stable. Keep every milestone small enough to test.
