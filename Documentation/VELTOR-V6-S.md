# VELTOR V6 S — First Prototype Vehicle

## Purpose
The VELTOR V6 S is the first temporary test vehicle for CAR DRIVE PARKING. It is a fictional sport sedan concept. The current prototype uses simple generated shapes only; it is not the final 3D model.

## Prototype dimensions and setup
| Property | Initial value |
|---|---:|
| Vehicle mass | 1,450 kg |
| Body collider | 1.85 × 0.62 × 4.25 m |
| Wheel radius | 0.36 m |
| Wheel mass | 22 kg |
| Suspension travel | 0.20 m |
| Drive type | Rear-wheel drive |
| Motor torque | 900 Nm (prototype tuning value) |
| Brake torque | 2,500 Nm |
| Handbrake torque | 4,500 Nm |
| Maximum steering angle | 30° |
| High-speed steering angle | 10° |

These values are starting points for testing, not validated real-world vehicle specifications.

## Visual direction
- Original four-door sport sedan silhouette
- Deep blue paint as the temporary prototype color
- Dark glass
- Four simple tire and rim assemblies
- No real-world manufacturer logos or copied vehicle styling

## Tuning process
1. Confirm the vehicle sits correctly on its four wheels.
2. Tune suspension until the body settles without excessive bouncing.
3. Tune steering at low speed before high-speed behavior.
4. Tune acceleration and braking on a flat test surface.
5. Check reverse engagement and handbrake stability.
6. Profile performance on target mobile hardware.
